## How to use this file
Each item is a row in its category table with the columns the final data
model will need. Fill in real values only once confirmed by the client —
replace `UNVERIFIED` / `TBD` in place, don't delete the row structure.

**Column legend**
| Column | Meaning |
|---|---|
| Item (FR) | Name as seen on old menu / to confirm |
| Item (EN) | English name — mostly not yet translated |
| Description (FR) | To collect from client |
| Description (EN) | To collect from client |
| Sizes | Size options if applicable (e.g. pizza 8"/10"/12"/14") |
| Current price | **Must come from client — old menu prices excluded** |
| Featured | Yes/No — is this a signature/highlighted item? (TBD) |
| Available | Yes/No — still on the current menu? (TBD with client) |
| Image | Path once a real photo exists, e.g. `public/images/menu/...` |
| Notes | Anything else (allergens, spice level, old-menu-only, etc.) |
